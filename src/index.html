Năm bước của pipeline

Các job dưới đây chạy tuần tự theo needs: job sau chỉ bắt đầu khi job trước xanh.

  1. 01

    Lint

    ESLint + html-validate + Prettier bắt lỗi cú pháp, format trước khi tốn runner.

    idle
  2. 02

    Test

    Matrix Node 20 & 22: unit test, test nội dung HTML, smoke test HTTP trên dist.

    idle
  3. 03

    Build

    esbuild bundle & minify, hash tên file, tiêm metadata, upload artifact.

  4. 04

    Deploy

    Chỉ chạy trên main: đẩy artifact lên GitHub Pages bằng OIDC.

  5. 05

Sẵn sàng mô phỏng.

Vì sao demo này “thật”?

Không cần server

GitHub Pages là CDN miễn phí. Deploy thật, URL công khai, không phải thuê VPS hay cấu hình nginx.

Chạy trên hạ tầng GitHub

Mỗi job là một runner ubuntu-latest sạch, cài Node, chạy đúng lệnh như máy bạn.

Có bằng chứng

Trang hiển thị commit SHA, run number và thời điểm build — dữ liệu do pipeline tạo ra, không phải mock.

An toàn khi deploy

Pages chỉ nhận trên main, dùng OIDC + environment, có concurrency để không deploy chồng nhau.
